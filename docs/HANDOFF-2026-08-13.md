## Traps that cost time today

- Long host-side encodes must be launched **detached** (`docker exec -d ... > log 2>&1`, then poll).
  A plain `ssh docker exec` dies at the 2-minute tool timeout and orphans children.
- Background waiter shells get reaped; use `Monitor` with `persistent: true` instead.
- `--binary` in the bench harness is **per invocation, not per arm**. One invocation per binary or
  arms silently run on the wrong encoder.
- xav auto-crops (1920x1080 → 1920x816 on closeenc), so frame-comparison crops need the offset or
  the source panel will not align.
- `-ss` before `-i` seeks to the nearest keyframe; use `select=eq(n,N)` for frame-exact stills.
